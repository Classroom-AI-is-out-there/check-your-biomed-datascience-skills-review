# Задание 1: Классификация табличных данных с учителем

Постройте воспроизводимый конвейер классификации клинических рисков на основе общедоступной обучающей таблицы. Задание содержит две связанные целевые переменные: `prediction` для высокого сердечно-сосудистого риска и `Статус_глюкозы` для статуса глюкозы. В базовом ноутбуке также показаны PCA для исследовательского анализа и нечёткий KNN для оценки неопределённости в пограничной группе по глюкозе.

## Данные

- Обучающие данные: `dataset/task1/train.csv`
- Признаки тестовой выборки: `dataset/task1/test_features.csv`
- Обучающий файл содержит `patient_id`, клинические признаки, `prediction`, `Статус_глюкозы` и `Доклинический_риск`.
- `test_features.csv` содержит идентификаторы пациентов и столбцы признаков, но не содержит целевых меток.
- В нескольких лабораторных столбцах есть пропуски. Импьютеры и масштабаторы необходимо обучать только на обучающих данных.

## Что необходимо сделать

1. Исследовать распределения, пропуски, корреляции и баланс классов.
2. Отделить признаки от всех целевых столбцов и использовать стратифицированное разделение на обучающую и валидационную выборки.
3. Обработать пропуски числовых признаков и при необходимости стандартизировать данные.
4. Обучить классификатор для `prediction`, например SVM из базового ноутбука, с балансировкой классов.
5. Оценить модель на отложенной выборке по Accuracy, Recall, Specificity, Precision, F1, ROC-AUC, матрице ошибок и ROC-кривой.
6. Для пациентов с `Глюкоза_натощак_ммоль_л` в диапазоне 5.4–6.5 ммоль/л реализовать или улучшить нечёткий KNN. Рассчитать степени принадлежности к классам, скор риска и случаи неопределённости без использования тестовых меток.
7. Объяснить клинические ограничения: данные являются симулированными, модель поддерживает, но не заменяет клиническое решение, а выбор порога влияет на число ложноотрицательных и ложноположительных прогнозов.

## Ожидаемые визуализации и отчёт

- Распределения признаков по группам и представление с помощью корреляционного анализа или PCA.
- Матрица ошибок и ROC-кривая для сердечно-сосудистого риска.
- Распределение нечётких скоров риска, значения принадлежности для примеров пациентов и анализ неопределённости.
- Отчёт объёмом не более 2000 знаков о предобработке, работе с дисбалансом, важных признаках, слабых классах и клинической интерпретации.

## Контракт отправки

- Запишите прогнозы для каждой строки `dataset/task1/test_features.csv` в `outputs/task1_predictions.csv`.
- Обязательные столбцы: `patient_id`, `prediction`.
- Сохраните исходные идентификаторы пациентов без изменений: одна строка на каждый объект, без пропусков.
- Нельзя использовать тестовые признаки для обучения предобработки или модели; тестовые метки использовать запрещено.
- Решение может быть представлено в `your-sollution/task1_solution.py` или `your-sollution/task1_solution.ipynb`.

Разрешены `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn` и библиотеки, перечисленные в требованиях задания.
