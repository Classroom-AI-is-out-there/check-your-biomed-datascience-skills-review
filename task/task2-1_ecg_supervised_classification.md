# Задание 2.1: Классификация сердечных сокращений по ЭКГ с учителем

Обучите классификатор на размеченных сегментах ЭКГ и предскажите класс ритма для каждого отложенного сердечного сокращения. В репозитории находится набор на основе ECG5000 с пятью целочисленными классами.

## Данные

- Обучающие данные: `dataset/task2_1/train.csv`
- Признаки тестовой выборки: `dataset/task2_1/test_features.csv`
- `train.csv` содержит `heartbeat_id`, `prediction` и столбцы сигнала `t_000`–`t_139`.
- `test_features.csv` содержит `heartbeat_id` и 140 столбцов сигнала, но не содержит меток.
- Идентификаторы классов: 0–4. Распределение классов сильно несбалансировано, поэтому его нужно исследовать по обучающим данным.

## Что необходимо сделать

1. Загрузить и исследовать одномерные сигналы длиной 140 точек.
2. Создать стратифицированные обучающую, валидационную и тестовую выборки из общедоступных размеченных данных.
3. Обучить нормализацию только на обучающей части.
4. Реализовать одномерную модель, например PyTorch 1D CNN из базового ноутбука. Использовать взвешенную функцию потерь или другой документированный способ работы с дисбалансом.
5. Использовать macro F1 на валидации для выбора модели или ранней остановки.
6. Оценить итоговую модель по Accuracy, macro F1, показателям для каждого класса и матрице ошибок.
7. Обсудить, какие классы сокращений путаются чаще всего и как на это влияют морфология сигналов и редкость классов.

## Ожидаемые визуализации и отчёт

- Представительные сигналы всех пяти классов.
- Графики функции потерь и macro F1 на обучении и валидации.
- Матрица ошибок.
- Отчёт объёмом не более 2000 знаков о предобработке, работе с дисбалансом, ошибках и возможных улучшениях.

## Контракт отправки

- Запишите прогнозы для каждой строки `dataset/task2_1/test_features.csv` в `outputs/task2_1_predictions.csv`.
- Обязательные столбцы: `heartbeat_id`, `prediction`.
- Сохраните идентификаторы сердечных сокращений без изменений; прогнозы должны быть целыми ID классов 0–4, без пропусков.
- Нельзя использовать отложенные метки при обучении или выборе модели.
- Решение может быть представлено в `your-sollution/task2_1_solution.py` или `your-sollution/task2_1_solution.ipynb`.

Используйте зависимости из `task/task2_1/requirements.txt`.
