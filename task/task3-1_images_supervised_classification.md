# Задание 3.1: Классификация гистопатологических изображений с учителем

Обучите CNN для девяти классов на общедоступных изображениях, производных от PathMNIST, и предскажите класс ткани для каждого отложенного изображения. В этом репозитории используется локальная выборка фиксированного размера, а не полная загрузка MedMNIST.

## Данные

- Обучающий архив: `dataset/task3_1/train.npz`
- Архив с отложенными признаками: `dataset/task3_1/test_features.npz`
- Оба архива содержат `images`; обучающий также содержит целочисленные метки `prediction` и `label_names`, а отложенный содержит `image_id`.
- Изображения имеют размер `28 x 28`, формат RGB и тип `uint8`. Целевые классы имеют ID 0–8.

## Что необходимо сделать

1. Загрузить локальный архив и создать стратифицированное разделение обучающих данных на обучение и валидацию.
2. Преобразовать изображения в тензоры и нормализовать их согласно базовому решению: масштабировать пиксели в [0, 1], затем применить среднее 0.5 и стандартное отклонение 0.5.
3. Определить и обучить CNN с девятью выходами. Отслеживать качество на валидации и контролировать переобучение с помощью остановки или сохранения лучшего состояния.
4. Оценить Accuracy, macro F1 и построить матрицу ошибок. Привести результаты по классам и обсудить дисбаланс, если он присутствует.
5. Сгенерировать прогнозы для отложенного архива без использования его меток.

## Ожидаемые визуализации и отчёт

- Размеченные примеры изображений из обучающей выборки.
- Графики функции потерь и Accuracy или macro F1 на обучении и валидации.
- Матрица ошибок и, по возможности, примеры ошибок.
- Отчёт объёмом не более 2000 знаков о предобработке, архитектуре, работе с дисбалансом и слабых классах.

## Контракт отправки

- Запишите по одному прогнозу на каждое отложенное изображение в `outputs/task3_1_predictions.csv`.
- Обязательные столбцы: `image_id`, `prediction`.
- Сохраните `image_id` без изменений; прогнозы должны быть целочисленными ID 0–8, без пропусков.
- Решение может быть представлено в `your-sollution/task3_1_solution.py` или `your-sollution/task3_1_solution.ipynb`.

Используйте зависимости из `task/task3_1/requirements.txt`. Локальный архив является источником данных для этого задания; загрузка `medmnist` из сети не требуется.
